새 현장 등록

첨부는 등록 카드의 첫 댓글로 들어갑니다. 캐드(.dwg)는 보통 용량이 커서 드라이브 링크를 권장합니다. 이후 파일은 카드 댓글에서 계속 올릴 수 있어요.

🔗 팀 공유 설정 (Firebase)

검토 대시보드(카드·댓글·단계·첨부)를 팀원과 실시간으로 공유합니다. 연결하면 누가 어디서 열어도 같은 내용이 보이고 즉시 반영돼요. 연결 전에는 이 브라우저에만 저장됩니다.

처음 한 번 설정 (5분)
① console.firebase.google.com 접속 → 프로젝트 만들기
② 좌측 빌드 → Firestore Database → 데이터베이스 만들기 (테스트 모드로 시작)
③ 프로젝트 개요 옆 ⚙️ → 프로젝트 설정 → 내 앱 → 웹(</>) 추가
④ 화면에 나오는 firebaseConfig = { … } 부분을 통째로 복사
⑤ 아래 칸에 붙여넣고 연결. 팀원들에게는 이 파일과 같은 설정값만 주면 끝.
💬 잔디(JANDI) 검토 알림 — 댓글에서 @팀원 태그하면 잔디 토픽으로 알림이 갑니다.
① 잔디 검토 토픽 → 커넥트(우측 상단 …) → 인커밍 웹훅 → 추가
② 생성된 Webhook URL을 복사해 아래에 붙여넣기 → 닫기로 저장.
