이 앱이 하는 일

현장 정보와 동별 물량만 넣으면 견적 발행부터 팀 검토까지 한 곳에서 끝냅니다.

  • 내역서 자동 작성 — 동별 면적·공법을 넣으면 ㎡당 실행단가와 총공사비가 자동 계산됩니다.
  • 물량 검증 — 위성사진으로 측정면적을 읽어 내역 면적과 비교, 검토율(정상/주의/오류)을 보여줍니다.
  • 검토 대시보드 — 만든 내역서를 팀 검토방(칸반)에 올려 단계별로 관리하고, 완료 시 구글시트에 자동 기록됩니다.

기본 흐름

상단의 ①~⑤ 단계를 따라가면 됩니다. 각 단계는 자동으로 다음으로 이어집니다.

  1. ① 현장·물량 — 발주처·요청사·현장 주소를 넣고, 전체 동수를 입력해 동별 면적을 채웁니다. (캐드/PDF 자동입력 가능)
  2. ② 단가·기준 — 내부단가/협력사 단가를 고르고 공법을 ‘사용’ 체크합니다.
  3. ③ 자동견적 — 일위대가·산출내역서·원가계산서가 자동 산출됩니다.
  4. ④ 물량검증 — 위성사진으로 측정면적을 확인합니다.
  5. ⑤ 발행·검토방 — 엑셀로 저장하거나 검토방에 올립니다.

화면 1 현장·물량 입력

① 현장·물량 단계 — 현장 정보를 넣고 전체 동수를 입력합니다.

1발주처 — 아파트(현장) 이름. 검토방 카드의 제목이 됩니다.
2요청사 — 의뢰 업체·담당자. (예: ㈜부영씨엔씨 정윤찬 대표)
3단지 전체 동수 — 숫자를 넣으면 아래 동별 입력칸이 자동 생성됩니다. 동마다 공법별 면적·둘레를 입력하세요. (캐드/PDF 올리면 자동)

화면 2 공법 선택 → 물량 자동입력

① 현장·물량 단계 — 공법을 고르고 캐드/PDF를 올리면 동별 물량이 바로 들어옵니다.

1공법 선택 — 이 현장에 쓸 공법(싱글·슬라브·배수로·금속기와·PVC·박공지붕)을 고릅니다. 고른 공법만 아래 동별 입력칸에 나타납니다.
2캐드/PDF로 자동입력 — 캐드(.dwg/.dxf)나 글자가 살아있는 PDF를 올리면 동별 면적·둘레가 자동으로 채워집니다. (빨강=싱글/금속기와 · 녹색=옥탑 · 파랑=슬라브/배수로)
3동별 면적 — 각 동의 면적이 공법별로 바로 들어옵니다. 직접 입력하거나 수정할 수도 있습니다.
참고옥상·옥탑 5% 할증은 이 아래 ‘면적 계산식’에서 공법별로 따로 켜고 끌 수 있습니다.

화면 3 발행 · 검토방에 올리기

⑤ 발행·검토방 단계 — 엑셀 저장 이름을 정하고 검토방에 올립니다.

1파일명 구분 — 초안본/최종본, 수정본(1차·2차), 여러 안(1안·2안).
2저장 파일명 미리보기 — 실제 저장될 엑셀 이름. (예: 초안본_2026 POUR 컨설팅내역서_아산 모종캐슬어울림2단지_26.09)
3마감날짜 — 검토방 카드 ‘요청사’ 아래에 ‘마감’으로 표시.
4검토방에 올리기 — 대시보드에 카드로 등록. 이때 총공사비가 ‘최종금액’으로 저장됩니다.

화면 4 검토 대시보드

올린 내역서를 4단계(초안본 검토 → 완료 → 최종본 검토 → 완료)로 관리합니다.

1카드 제목 — 발주처(아파트 이름).
2공법별 ㎡단가 — 싱글·슬라브 등 실행단가.
3완료 칸(핑크) — 완료 단계는 연핑크로 구분. 카드를 끌어 옮기면 단계가 바뀝니다.
4팀 공유 — 켜면 팀원·다른 기기와 실시간 동기화.
폰에서는 목록으로휴대폰으로 열면 4칸 칸반 대신 카드가 위→아래 목록으로 자동 전환됩니다. 검색해서 나온 현장을 눌러 댓글(변경 내역)을 바로 확인하기 편합니다. 상단 ‘☰ 목록 / ▦ 칸반’ 버튼으로 언제든 바꿀 수 있어요.
카드 삭제는 비밀번호가 필요합니다카드의 삭제를 누르면 비밀번호(13546)를 물어봅니다. 댓글·첨부·기록이 함께 지워지고 되돌릴 수 없으니, 담당자만 삭제하세요.

화면 5 자재단가 잠금

자재단가 마스터 DB — 기본으로 잠겨 있어 아무나 바꿀 수 없습니다.

1잠금 안내 — 자재단가는 기본으로 잠겨 수정이 막혀 있습니다.
2잠금 해제 — 담당자만 이 버튼을 눌러 비밀번호(13546)를 입력하면 수정할 수 있습니다. 끝나면 다시 잠가주세요.
